# Spike S4 - Injeção de Entrada SendInput + Scan Codes ABNT2

## Objetivo
Validar injeção de entrada usando `SendInput` da API do Windows com scan codes no layout ABNT2, garantindo que nenhuma tecla fique "presa" após o encerramento.

## Metas
- Todos os eventos injetados com sucesso (teclas, mouse, roda)
- State limpo ao final: nenhuma tecla pressionada
- Suporte a layout ABNT2 (scancodes corretos)

## Resultados
- Tecla A (scancode 0x1E): injetada e liberada ✓
- Tecla S (scancode 0x1F): injetada e liberada ✓
- Tecla Enter (scancode 0x1C): injetada e liberada ✓
- Clique esquerdo: pressionado e solto ✓
- Roda do mouse (wheel up): injectada ✓
- State limpo ao final: **VERIFICADO** (todas as teclas receberam KEYUP correspondente)

## Conclusão
**Aceito** — injeção SendInput funcionou corretamente com scancodes ABNT2 e liberação adequada de teclas. Nenhum modificador ficou pressionado após o término.

Próximos passos: integrar ao host `prysmview-svc` com suporte a layout ABNT2 como entrada padrão.
